# 📚 Project Functionality

The Fitness Tracker App helps users manage and track their daily workouts.

Users can:
- Add workout information
- Track workout duration
- Monitor calories burned
- View total workouts
- Delete workout records

All data is stored using browser Local Storage, so the information remains saved even after refreshing the webpage.
